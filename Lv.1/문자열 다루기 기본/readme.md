### **문제 설명**

문자열 s의 길이가 4 혹은 6이고, 숫자로만 구성돼있는지 확인해주는 함수, solution을 완성하세요. 예를 들어 s가 "a234"이면 False를 리턴하고 "1234"라면 True를 리턴하면 됩니다.

### 제한 사항

- `s`는 길이 1 이상, 길이 8 이하인 문자열입니다.
- `s`는 영문 알파벳 대소문자 또는 0부터 9까지 숫자로 이루어져 있습니다.

### 입출력 예

| s      | return |
| ------ | ------ |
| "a234" | false  |
| "1234" | true   |

<hr/>

숫자만 포함된 문자열인지 확인: /^\d+$/.test(s)

- ^는 문자열의 시작을 의미
- \d+는 하나 이상의 숫자를 의미
- $는 문자열의 끝을 의미
- .test(s)는 정규 표현식이 s 문자열에 대해 숫자만 포함되어 있는지 확인

<hr/>

- 예: "1234"는 숫자만 포함되어 있으므로 true를 반환
- 예: "123a"는 숫자와 문자가 섞여 있으므로 false를 반환
