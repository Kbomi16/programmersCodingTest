### **문제 설명**

효진이는 멀리 뛰기를 연습하고 있습니다. 효진이는 한번에 1칸, 또는 2칸을 뛸 수 있습니다. 칸이 총 4개 있을 때, 효진이는

(1칸, 1칸, 1칸, 1칸)

(1칸, 2칸, 1칸)

(1칸, 1칸, 2칸)

(2칸, 1칸, 1칸)

(2칸, 2칸)

의 5가지 방법으로 맨 끝 칸에 도달할 수 있습니다. 멀리뛰기에 사용될 칸의 수 n이 주어질 때, 효진이가 끝에 도달하는 방법이 몇 가지인지 알아내, 여기에 1234567를 나눈 나머지를 리턴하는 함수, solution을 완성하세요. 예를 들어 4가 입력된다면, 5를 return하면 됩니다.

### 제한 사항

- n은 1 이상, 2000 이하인 정수입니다.

### 입출력 예

| n   | result |
| --- | ------ |
| 4   | 5      |
| 3   | 3      |

### 입출력 예 설명

입출력 예 #1

위에서 설명한 내용과 같습니다.

입출력 예 #2

(2칸, 1칸)

(1칸, 2칸)

(1칸, 1칸, 1칸)

총 3가지 방법으로 멀리 뛸 수 있습니다.

### 피보나치

| n   | 방법 수 (f(n)) | 이전 두 수의 합? |
| --- | -------------- | ---------------- |
| 1   | 1              | -                |
| 2   | 2              | -                |
| 3   | 3              | 1 + 2            |
| 4   | 5              | 2 + 3            |
| 5   | 8              | 3 + 5            |
| 6   | 13             | 5 + 8            |
| 7   | 21             | 8 + 13           |
| ... | ...            | ...              |

```js
for (let i = 3; i <= n; i++) {
  const next = (a + b) % MOD
  a = b
  b = next
}
```

- n = 3부터 시작해서, f(n) = f(n-1) + f(n-2) 식으로 값을 구함.
- a는 이전 값 (f(n-2)), b는 직전 값 (f(n-1))
- next는 현재 값 (f(n))
- 이후 a와 b를 한 칸씩 앞으로 밀어줌

### 🧠 예시 n = 5

| i   | a(f(n-2)) | b(f(n-1)) | next (a+b)%MOD |
| --- | --------- | --------- | -------------- |
| 3   | 1         | 2         | 3              |
| 4   | 2         | 3         | 5              |
| 5   | 3         | 5         | 8              |
